# HITS NOW 선정 기준과 문구 규칙

## 선정 기준 (HITS 세계관 부합 — 가장 중요한 취향)
소개하는 뉴스·사례가 HITS 세계관과 맞아야 한다. 한 건이 네 요소를 다 가질 필요는 없고, 하나 이상이 뚜렷하면 후보다.
- **Hook**: 고객의 진짜 문제·욕구를 발견해서 시작했는가
- **Insight**: 같은 상품의 가치를 새롭게 번역·설계했는가(기능이 아니라 의미를 바꿨는가)
- **Tale**: 고객이 이야기하고 싶어지게 만든 방식(캠페인, 네이밍, 경험 설계)이 있는가
- **System**: 한 번 팔고 끝나지 않고 반복·확장·팬덤으로 이어지는 구조가 있는가

제외: 인사 이동(CMO 교체 등), 인수합병·실적 발표, 광고기술·플랫폼 운영 팁, 바이럴 자체가 목적인 이벤트, 논란이 핵심인 캠페인, 숫자만 있고 "왜 팔렸는지"가 없는 사례.

## 구성
- 전부 **해외** 사례·뉴스. 태국은 1~2건까지. 지역을 분산한다(한 회차에 같은 나라 2건 이하).
- 한 회차 = 표지 1 + 뉴스 5(1건 = 카드 1장) + 오늘의 인사이트 1 = **7장**.
- 이전 회차에서 다룬 사례는 제외한다(`data/now.json` 의 `news[].brand` 확인).
- 후보 15~20건 → 상위 8건 이상은 원문을 끝까지 읽고 → 5건 선정. 사진을 구할 수 있는지도 선별 단계에서 본다.

## 사실 확인
- 숫자·날짜·인용은 **원문을 열어 확인한 것만** 쓴다. 확인 못 한 숫자는 쓰지 않는다.
- 브랜드·대행사가 낸 수치와 브랜드 의뢰 조사는 카드 출처 줄에 밝힌다("수치는 대행사 발표", "조사 수치는 브랜드 의뢰 조사").
- 기사에 없는 내용(국적, 설립 연도, 규모 등)은 쓰지 않는다. 유료로 막혀 읽힌 부분이 얇으면 선정에서 뺀다.
- 최신성: 가능하면 48시간 이내. 더 오래된 건 이유를 보고서에 적는다.

## 문장 톤
- "~다" 평서문으로 짧게 끊는다. 설명보다 장면 위주. 한 카드 본문은 4~5문장, 공백 포함 약 200자 안팎(최대 약 230자).
- 헤드라인은 한 줄(공백 포함 약 22자 이내). 칩(tag)은 12자 안팎의 짧은 라벨.
- 모든 문구는 한국어로 쓰고 브랜드·캠페인명은 원문 표기를 따옴표(“ ”)로 둔다.
- 사용자가 확정한 문구는 임의로 고치지 않는다(오탈자·표현 수정도 사용자 지시가 있을 때만).

## 오늘의 인사이트 (7장)
5건을 아우르는 한 줄. 평서형 또는 지침형("~하라")은 사용자가 정한다. 첫 호는 "상품은 그대로였다. 바뀐 건 상품이 놓인 자리다.", 2호는 "상품을 설명하는 것이 아니라, 고객이 이미 하고 있는 행동에서 출발하라".
강조 구절은 `insight_highlight` 로 지정한다(파란색으로 표시됨).

## 사진
- 기사에 실린 홍보 이미지를 쓴다. 이용 조건은 사용자가 최종 컨펌 때 검수하므로, 의심되는 사진(선정적·권리 불명·해상도 낮음·브랜드가 안 보임)은 보고서에 미리 표시하고 대체 컷을 함께 준다.
- 해상도가 낮은 원본(예: 700px대)은 확대되어 흐리다고 알린다.
- 카드에는 `이미지 출처: 매체명` 을 작게 표기한다.
- 사진은 카드마다 1장. 가로로 긴 사진은 `pos`(object-position)로 잘림 위치를 조정한다.
